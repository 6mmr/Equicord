# StreamBlur

A [Vencord](https://vencord.dev) plugin. When you open a DM while streaming, the whole conversation is blurred. Click it to reveal it. The blur comes back every time you switch conversations.

## Installation

```sh
cd Vencord/src/userplugins
git clone https://github.com/LilNesquuik/StreamBlur streamBlur
cd ../.. && pnpm build
```
